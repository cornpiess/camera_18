Camera18 原生校准工作台

编辑配方、比较样张。所有效果图由应用同源的 Core Image 渲染器生成；此页面不再运行另一套滤镜。文件只在本机打开，不上传。

1 · 当前配方

请导入 assets/camera-profiles.json。已有手机 override 请先导出，再导入此处。

导出只代表编辑完成，不代表已经校准。导入应用前须经过项目校验、原生渲染和独立样张验收。配方修改不会自动覆盖手机中的 override。

2 · 同一构图，三张对照

显示完整构图，不裁切、不加 CSS 滤镜。对齐曝光、构图和光线后比较肤色、典型颜色、灰阶及高光；正常观看与 100% 检查分别进行。浏览器显示不替代 iPhone 验收。

3 · 使用唯一渲染依据

在 macOS 运行；编译与应用相同的 CameraProfileRenderer.swift，不出安装包、不触发云端构建。先运行自检，失败时停止校准。

bash scripts/native-calibration.sh self-test

bash scripts/native-calibration.sh render \
  assets/camera-profiles.json ricoh_negative \
  modules/camera-engine/ios/LUTs source.jpg rendered.png final

有独立训练／验收样本后，拟合单个候选 LUT。fit 输出保留 v1 完整RGB约定；不要只改标签当作 v2 的纯颜色cube使用。候选不自动进入生产。

node scripts/calibrate-camera.js fit dataset.json ricoh_negative calibration-output/grit-n

bash scripts/native-calibration.sh probes \
  calibration-output/grit-n/profile.json ricoh_negative \
  calibration-output/grit-n calibration-output/grit-n/probes.json \
  calibration-output/grit-n/native.json final

node scripts/calibrate-camera.js evaluate dataset.json calibration-output/grit-n/native.json
